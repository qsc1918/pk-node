**结论：全服务同一套参数。** 不存在「主域一套、练习一套」——
`leo-star` / `leo-math` / `leo-game-pk` / `leo-profile` / `solar-activity` / `accounts`
用的都是上表这一组值。

旧代码把参数拆成两套表且**两套都错**：`3.140.1` 落后、`3.143.1` 超前（真机不存在该版本），
`android35` / `fenbi` / `110` / `1.78` 与真机逐字值均不符
→ 被 `solar-encoder` 判异构 → **400 / 417**。

## 二、真机 UA（逐字）

```
Leo/3.141.1 (Redmi25053RT47C; Android 17; Scale/3.25)
```

⚠️ **两个易错点**：

1. `Android 17` 是 **UA 里的 Android 版本号，不是 SDK 号**。
   query 的 `platform=android37` 用的才是 SDK 号（37）。
   两个值必须分别按真机来 —— 把 sdk(37) 填进 UA 会被判异构。
2. 版本名 `3.141.1` 必须跟 `version` 参数一致。

## 四、接口路径：`{client}` = `android`

真机 bundle 里（`index-legacy.DqAYjRZL.js`）：

```js
R = t => { var e = y() ? {client: "android", productId: C.android}
              : v() ? {client: "iphone", ...} : ... }
```

所以真实路径是：

```
/leo-game-pk/android/math/pk/home      ← 注意：**没有 /api/ 这一层**
/leo-star/android/exercise/rank/pre-fetch
/leo-activity/android/activity/pk/daily/award
```

**两套路径并存**：
- `/android/...` —— 真机当前在用（新）
- `/api/...` —— 早期 bundle 用的（旧，保留兼容）

pk-node 的 `PK_PRIORITY_PATHS` 等白名单**必须两套都列**，只写一套会让另一套失去优先权。
